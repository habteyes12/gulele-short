# Report outline (export to PDF/Word when filled)

Write it yourself and tie each claim to a file, run_id or log line.

1. **What I set out to make, and for whom.** Story, audience, intent (see DESIGN.md).
2. **What I learned from my audience.** Test 1 (radio cut) and test 2 (near-final). Quote the reactions. Name the storyboard changes (`revisions`).
3. **The hardest problem and how I solved it.** For example: Amharic TTS timing vs the 90 s limit, character consistency, Kaggle GPU. Give the evidence.
4. **A suggested practice that beat my instinct.** For example: the radio cut before pictures, the JSON contract, or the reference sheet first. Give the evidence.
5. **A suggested practice that did not help me.** Say honestly why, with evidence.
6. **Ceiling work.** What you tried beyond the floor and what it taught you. For example: a blind Ken Burns vs Wan test, Afaan Oromo or Tigrinya narration with documented failures, `pipeline.costs`, reuse as a CLI.
7. **What I would build next.**
